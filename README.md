# Песочница Сверхновых 🚀

Космическая 2D-песочница на Python и Pygame с физикой частиц, чёрными и белыми дырами.

## 🎮 Управление

* **ЛКМ** — Взрыв / Создать частицы
* **Зажать ПКМ** — Спавн / Перемещение Чёрной дыры
* **Зажать W** — Спавн / Перемещение Белой дыры
* **R** — Спавн ракеты / Управление ракетой
* **H** — Спавн дрона-охотника
* **S** — Космическая станция
* **B** — Ударная волна
* **Стрелки Вверх / Вниз** — Регулировка мощности взрыва
* **C** — Очистить экран
